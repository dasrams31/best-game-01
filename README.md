VOIDLIGHT is a neon arena survival shooter: pilot the last lantern-ship, hold the drift against waves of void creatures, pick an upgrade after every wave, and chase the high score.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or serve `game/` with any static server and open `index.html`. No build step, no network requests, no assets to download: the whole game is static files under `game/`.
